工事かんたん請求 PWA v9

【更新内容】
・見積書／請求書／領収書PDFのページツリー参照番号を修正。
・PDFは端末内のCanvasで生成し、外部PDFサービスや外部スクリプトへ顧客データを送信しません。
・工事履歴から見積書PDF・請求書PDFを作成できます。領収書PDFは入金済み工事のみ作成できます。
・新規工事の保存ボタンではPDFを自動表示・ダウンロードせず、保存後は工事履歴から必要な書類を作成します。
・保存完了時の通知ポップアップは表示せず、保存失敗時のみエラーを表示します。
・PWAキャッシュをv9へ更新し、更新後の画面を読み込みやすくしました。

【公開・更新方法】
1. ZIPを展開します。
2. 中身（index.html、manifest.webmanifest、service-worker.js、iconsフォルダー、README.txt）をGitHub Pagesのリポジトリ直下へアップロードします。
3. Commit changes後、GitHub Pagesの更新完了を待ちます。
4. 既存PWAは閉じて再起動し、必要ならサイトデータ／キャッシュを更新してください。

【データと安全性】
・顧客データはPDF生成のために外部サーバーへ送信しない設計です。
・PDFファイル自体は暗号化されません。共有時は送信先を確認してください。
・端末のブラウザ保存領域は端末・ブラウザごとに分かれ、自動同期しません。
・バックアップファイルは暗号化機能を利用し、パスワードを安全に保管してください。
