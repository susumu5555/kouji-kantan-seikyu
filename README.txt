工事かんたん請求 PWA 試作パッケージ

【公開方法】
1. ZIPを展開し、中身（index.html、manifest.webmanifest、service-worker.js、iconsフォルダー）をHTTPS対応の静的Webホスティングへアップロードします。
2. すべて同じ階層に配置してください。
3. 発行されたhttps://のURLをスマホ・PCで開きます。
4. Android/Chrome: メニューから「アプリをインストール」または「ホーム画面に追加」。
   iPhone/Safari: 共有メニューから「ホーム画面に追加」。
   PC/対応ブラウザ: アドレスバーまたはブラウザメニューからインストール。

【保存データの暗号化】
・顧客情報、工事履歴、会社設定、工事項目などの通常保存データを、Web Crypto APIのAES-256-GCMで暗号化してブラウザ内に保存する実装を追加しました。
・鍵は入力したパスワードとPBKDF2-SHA-256から導出します。パスワードそのものは保存しません。
・初回起動時に4文字以上のパスワードを設定します。次回以降は起動時に入力してロックを解除します。
・パスワードを忘れると保存データを復号できません。4文字は安全性が低いため、可能なら長く複雑なパスワードを使用してください。必ず別の安全な場所に保管してください。
・パスワード設定前の旧形式データがある場合、初回ロック解除時に暗号化形式へ移行し、旧形式の保存データを削除します。
・暗号化バックアップは従来どおり別途作成できます。端末間同期はありません。

【重要な注意】
・暗号化実装を追加しましたが、実際の端末・ブラウザでの初回移行、再起動後の解除、データ保存、バックアップ復元の一連の実機テストは未完了です。実データを入力する前にテストデータで確認してください。
・ブラウザの保存領域が消去された場合や端末故障時に備え、暗号化バックアップを定期的に別の場所へ保存してください。
・PWAの保存領域は同じサイトURLのブラウザごとに分かれ、端末間の自動同期はありません。
・このパッケージを作成しただけではインターネット公開は完了していません。HTTPS対応ホスティングへのアップロードが必要です。
・アプリの暗号化機能にはHTTPS対応ブラウザが必要です（localhostでの開発を除く）。


【PDF作成と工事履歴】
・見積書、請求書、領収書はブラウザ内のCanvasでPDFを生成します。
・PDF生成に外部CDNや外部スクリプトを使用せず、顧客情報や書類内容をPDF生成のためにサーバーへ送信しません。
・PDFは端末へダウンロードされます。メールやLINEへの添付は、端末のファイル共有機能から行ってください。
・工事履歴から見積書PDF、請求書PDFを作成できます。領収書PDFは入金済みの工事のみ作成できます。
・PDFは画像ベースで作成するため、文字のコピーや検索はできない場合があります。
